# Материалы о Екатеринбурге

Небольшой стартовый набор для сайта Чкаловского района: четыре события, две истории предприятий с тремя текстовыми слайдами каждая, два описания подрайонов и четыре вопроса квиза. Тексты написаны для сайта по проверенным источникам; обложки — графические карточки с датами, а не исторические фотографии.

## Источники

- [Президентская библиотека: история Екатеринбурга](https://www.prlib.ru/news/2020815) — основание города и запуск Уктусского завода.
- [Екатеринбурговедение: Уктус](https://ekavedenie.ru/uktus) — промышленная история Уктуса.
- [Уральская торгово-промышленная палата: Уралхиммаш](https://pobeda.uralcci.com/uralhimmash) — первая продукция и военное становление предприятия.
- [Государственный архив: образование Чкаловского района](https://gaspi-so.ru/news/1390-rajon-zamechatelnykh-perspektiv-chkalovskomu-rajonu-ekaterinburga-80-let) — события 1943 года.

Соответствие записей источникам сохранено в `content.json`. Проверено 13 октября 2026 года.

## Ручное добавление

```powershell
.venv/Scripts/python.exe backend/scripts/fill_ekaterinburg.py --base-url http://localhost:8000 --report .deploy-local/content-report.json
```

Скрипт спрашивает email и пароль администратора; их также можно передать через переменные `CONTENT_ADMIN_EMAIL` и `CONTENT_ADMIN_PASSWORD`. Создание выполняется через API, изображения попадают в настроенное хранилище. Перед повторным запуском совпадающие события, названия предприятий и вопросы пропускаются. Существующие описания и изображения подрайонов не заменяются. Отчёт сохраняет идентификаторы созданных записей для последующей ручной проверки или удаления.

Наполнение не выполняется автоматически при CI/CD и не меняет существующие материалы при обновлении приложения. Для частично созданной истории предприятия проверяйте оставшийся черновик в админке.
